# Excel-Dashboard-Delivery-Sales

## 📊 Dashboard Overview

The Delivery Sales Dashboard consolidates sales data from 2021-2022, offering multi-faceted analysis of delivery operations, regional performance, customer behavior, and profitability metrics through interactive visualizations.

![](https://github.com/Rajni0327/Excel-Dashboard-Delivery-Sales/blob/main/Screenshot%202025-10-18%20195302.png)

## 🎯 Key Features

### Interactive Filters

**Years (Date)**

**Region**

All filters support multi-selection and cross-filtering across all dashboard visualizations.

### For Dashboard Users

**Basic Navigation**:
1. Select year(s) from the Years filter (2021, 2022, or both)
2. Choose specific region(s) to analyze
3. Filter by delivery person to view individual performance
4. Click on chart elements for drill-down analysis

## 📊 Dashboard Insights & Analysis

### Performance Highlights

**Strongest Areas**:
- South West region leads in both sales volume and market share
- Customer C11 generates exceptional revenue (25,307)
- Northern regions show higher selling prices and margins

**Areas for Improvement**:
- South East region has lowest sales volume
- Mid-2022 sales dip needs investigation
- Some delivery personnel underutilized in certain regions

**Opportunities**:
- Expand top performer presence in underserved regions
- Develop targeted campaigns for South East growth
- Leverage seasonal patterns for promotional planning
- Cultivate relationships with customers C1-C8 to reach C11 levels
